# Release manifest

Use this checklist for every distributable release:

- [ ] Every included lyric, prompt, image, audio reference, and generated asset is listed.
- [ ] Provenance and applicable usage terms are recorded.
- [ ] Required attribution is included.
- [ ] No private files, credentials, or personal data are present.
- [ ] README links and product claims are accurate.
- [ ] Release version and date are recorded.
- [ ] A human reviewer approved the final package.

The repository license does not automatically grant rights to third-party or generated material inside the package.
